# DWP Service Desk Triage Summary

## Summary (one line)
New associate reports Copilot in Outlook cannot find any case-related emails she needs for context.

## Impact (who/how many/business urgency)
- Who: New associate (started this week) using Copilot in Outlook.
- How many: Single reported user (to-verify).
- Business urgency: Moderate; new starter unable to use a key productivity tool, impacting onboarding efficiency and case ramp-up (to-verify).

## Known facts
- Ticket reference: T-1002.
- User group/context: Legal – New associate, account created this week.
- Reported issue: Copilot in Outlook cannot find case emails when asked for context.
- Copilot can only surface emails the user's own mailbox contains; a new account will have an empty or very sparse mailbox.
- New accounts may also still be in the provisioning/indexing window for Microsoft Search and Copilot semantic index.

## Missing information to gather
- Whether the case emails exist in the user's mailbox at all, or whether they should have been shared/forwarded to her (to-verify).
- Whether the user's mailbox has been fully provisioned and is receiving mail (to-verify).
- Whether Microsoft 365 Copilot licence has been assigned to the new account (to-verify).
- How long since account creation — Microsoft Search indexing can take 24–72 hours for new accounts (to-verify).
- Whether the user can find the emails manually via Outlook search (without Copilot) (to-verify).
- Whether she has been added to any shared mailboxes or distribution groups relevant to the cases (to-verify).
- Whether colleagues with the same emails can use Copilot to find them successfully (to-verify).
- Exact Copilot prompt used (to-verify).

## Likely category
New account mailbox indexing delay and/or emails not yet present in user's mailbox — Copilot limited to content the user already has access to (to-verify).

## First diagnostic step
Confirm whether the case emails actually exist in the user's Outlook mailbox by having her search manually (Ctrl+E); if emails are absent, the fix is to forward or share them — not a Copilot fault; if present but Copilot still misses them, raise a Microsoft 365 Search indexing delay as the likely cause and advise retry after 48 hours.
