# DWP Service Desk Triage Summary

## Summary (one line)
Paralegal reports Copilot cannot summarise a client NDA stored in SharePoint, returning "I don't have access to that content."

## Impact (who/how many/business urgency)
- Who: Paralegal attempting to summarise a client NDA via Microsoft Copilot in SharePoint.
- How many: Single reported user so far (to-verify).
- Business urgency: Moderate; document review delay impacts legal workflow but no immediate client deadline confirmed (to-verify).

## Known facts
- Ticket reference: T-1001.
- User group/context: Legal – Paralegal.
- Reported issue: Copilot returns "I don't have access to that content" when asked to summarise an NDA.
- File location: A SharePoint folder the user has never directly opened before — she became aware of it via a meeting.
- Copilot cannot access a file unless the requesting user has at least read permissions to it.

## Missing information to gather
- Whether the user has ever directly navigated to or opened the SharePoint folder/file in question (to-verify).
- Whether the user can manually open the file in SharePoint without Copilot (to-verify).
- What SharePoint site and library the folder resides in (to-verify).
- Whether the folder has broken/unique permissions versus inheriting from the parent site (to-verify).
- Whether the user was explicitly granted access or only heard about the folder informally (to-verify).
- Whether other members of the legal team can access the same folder and summarise the NDA via Copilot (to-verify).
- Whether sensitivity labels or Information Protection policies are applied to the file or folder (to-verify).
- Exact Copilot entry point used (Copilot in SharePoint, Copilot in Teams, M365 Chat) (to-verify).

## Likely category
SharePoint permissions/access gap — user lacks direct access to the file, so Copilot correctly refuses to surface content (to-verify).

## First diagnostic step
Ask the user to navigate directly to the SharePoint folder and attempt to open the NDA manually; if she receives an "Access denied" or cannot locate the file, this confirms a permissions issue rather than a Copilot fault, and an access request or SharePoint admin permission grant should be raised.
