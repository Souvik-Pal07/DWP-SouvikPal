# Title: Migration Update

## Notification Message:
We are continuing to improve the Windows 11 migration experience, and most users should now be seeing a smoother rollout. Support teams are monitoring the situation closely and resolving issues as quickly as possible. If you are still affected, please contact the service desk or raise a support request.
