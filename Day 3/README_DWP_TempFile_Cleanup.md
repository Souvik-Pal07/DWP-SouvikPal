# DWP Temp File Cleanup Script (PowerShell 5.1)

This folder includes a safe temp-file cleanup script for Windows endpoints:

- Script: `DWP_TempFile_Cleanup.ps1`

The script is designed for service-desk use with dry-run support, per-file error handling, logging, summary reporting, and rollback.

## What the script does

- Scans temp locations recursively for files older than a configurable number of days.
- Skips locked files and logs the reason.
- Handles errors per file with try/catch so one failure does not stop the run.
- Logs every action to a timestamped log file.
- Archives files into a quarantine folder (instead of permanent delete) to enable rollback.
- Supports rollback from a manifest CSV created during cleanup.
- Remains idempotent across repeated runs.

## Parameters

- `-DryRun`
  - Cleanup mode only.
  - Shows and logs files that would be archived.
  - Makes no file changes.

- `-OlderThanDays <int>`
  - Cleanup mode only.
  - Default is `0`.
  - Includes files with `LastWriteTime <= now - OlderThanDays`.

- `-TargetPaths <string[]>`
  - Cleanup mode only.
  - Default:
    - `$env:TEMP`
    - `$env:WINDIR\Temp`

- `-QuarantineRoot <string>`
  - Cleanup mode only.
  - Default: `$env:ProgramData\DWP\TempCleanup\Quarantine`
  - Archived files are moved under a run-specific folder in this location.

- `-Rollback`
  - Switches script to rollback mode.

- `-ManifestPath <string>`
  - Rollback mode only, required.
  - CSV path generated by a previous cleanup run.

- `-LogRoot <string>`
  - Optional in all modes.
  - Default: `./Logs` (a Logs folder beside the script).

## Usage examples

### 1) Dry run (no changes)

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\DWP_TempFile_Cleanup.ps1 -DryRun
```

### 2) Cleanup files older than 7 days

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\DWP_TempFile_Cleanup.ps1 -OlderThanDays 7
```

### 3) Cleanup custom paths

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\DWP_TempFile_Cleanup.ps1 -OlderThanDays 3 -TargetPaths "C:\Windows\Temp","C:\Users\Public\Temp"
```

### 4) Rollback using manifest

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\DWP_TempFile_Cleanup.ps1 -Rollback -ManifestPath "C:\ProgramData\DWP\TempCleanup\Quarantine\<RunGuid>\manifest.csv"
```

## Logging and summary

- Every run creates a timestamped log file in `LogRoot`.
- End-of-run summary includes:
  - Mode
  - DryRun
  - OlderThanDays
  - ScannedFiles
  - EligibleFiles
  - ArchivedFiles
  - RestoredFiles
  - SkippedLocked
  - SkippedMissing
  - SkippedExisting
  - Errors
  - Start/End/Duration
  - Log file path
  - Manifest path

## Idempotency notes

- Cleanup mode only acts on files that currently exist and match age criteria.
- Already moved/deleted files are skipped without failure.
- Rollback mode skips restore when original file already exists, preventing overwrite side effects on repeated runs.

## Operational notes

- Run in an elevated PowerShell session if access-denied issues occur on protected folders.
- Quarantine storage should be monitored for capacity if used frequently.
- If desired, add a separate retention process for old quarantine runs after validation windows close.
