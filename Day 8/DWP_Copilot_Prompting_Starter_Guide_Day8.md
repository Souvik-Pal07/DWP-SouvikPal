# FinBridge 365 Copilot Prompting Starter Guide (Day 8)

Date: 2026-08-12  
Audience: Non-technical office staff at FinBridge

This guide is designed to help you get useful results from Microsoft 365 Copilot quickly, using simple prompts you can copy, adapt, and reuse.

## 1) A simple formula for good prompts

Use this easy pattern:

**Task + Context + Output + Tone + Limits**

You do not need to get this perfect. Even using 2-3 parts will usually give you a much better result.

- **Task**: What you want Copilot to do.
- **Context**: The meeting, email, document, or data it should use.
- **Output**: The format you want back (bullet list, email draft, table, etc.).
- **Tone**: Friendly, formal, concise, executive, etc.
- **Limits**: Word count, deadline, do/don't include.

### Quick template

"Please **[task]** using **[context]**. Give me **[output format]** in a **[tone]** tone. Keep it to **[limit]** and include **[must-have items]**."

Example:

"Please summarise this email thread using the last 5 replies. Give me 5 bullets in a professional tone. Keep it under 120 words and include owners and due dates."

## 2) Outlook prompt examples you can use today

### Example 1: Summarise a long email chain

"Summarise this email thread into 6 bullet points. Highlight decisions made, open questions, and actions with owner names and due dates. Keep it concise and ready to paste into Teams."

### Example 2: Draft a polite follow-up

"Draft a follow-up email to the vendor about the delayed invoice approvals. Keep the tone polite and firm. Ask for a confirmed timeline by Friday 3 PM and include a short subject line."

### Example 3: Prioritise inbox for this morning

"Review my unread emails from today and group them into: Urgent, Today, and This Week. For each urgent email, suggest a one-line reply I can send now."

## 3) Word prompt examples you can use today

### Example 1: Turn notes into a clear update

"Turn these meeting notes into a one-page project status update for managers. Use headings: Progress, Risks, Decisions, Next Steps. Keep the language plain and business-friendly."

### Example 2: Improve clarity and structure

"Rewrite this draft policy note so it is easier for non-technical staff to understand. Use short sentences, clear headings, and a professional tone. Keep all original meaning."

### Example 3: Create an executive summary

"Create a 150-word executive summary of this document. Focus on business impact, timeline, and key actions required this month."

## 4) Excel prompt examples you can use today

### Example 1: Spot trends in monthly data

"Analyse this table of monthly support tickets. Show the top 3 categories increasing over the last 3 months, and suggest one likely reason for each trend in plain language."

### Example 2: Prepare a clean summary for leaders

"Create a summary table from this spreadsheet showing total tickets by department, average resolution time, and percentage resolved within our target time. Format it for a leadership update."

### Example 3: Find outliers and next checks

"Find any numbers in this expense sheet that look unusually high or low, and tell me which rows they are in. Then suggest 3 checks I should do before sending this report to Finance."

## 5) Prompting tips that make answers better

- Ask for a specific format: "5 bullets", "email draft", "table with 3 columns".
- Add a clear audience: "for managers", "for customers", "for the Finance team".
- Set a limit: "under 120 words", "top 3 risks only".
- Ask for actions and owners when summarising meetings or threads.
- If the first answer is not quite right, ask again with one extra detail instead of starting over.

## 6) Data safety habit (from Day 1)

Keep the Day 1 habit: **protect data first**.

You can use Copilot confidently for everyday work. Just keep sensitive information inside approved FinBridge tools.

- Use Microsoft 365 Copilot within approved FinBridge systems for work content.
- Do **not** paste confidential client data, personal data, contracts, or financial details into external AI tools that are not approved by FinBridge.
- If you are unsure whether a tool is approved, check with IT before using it.

## 7) One-minute checklist before you press Enter

- Did I clearly say what I want Copilot to do?
- Did I include enough context?
- Did I ask for a specific output format?
- Did I set tone and length?
- Am I keeping confidential data inside approved FinBridge tools?
